# UX redesign: Phase 0 plan

Companion to `docs/ux-redesign.md` (the brief). Nothing here is application code. "Before" screenshots are in `docs/screenshots/before/` (24 screens x 390 / 768 / 1280 px, dark theme, WebP; seeded with 24 sample games, covers are generated placeholders because the sandbox can't reach the IGDB image CDN).

## 1. How the app is built today

**Stack and styling.** React 19 + react-router 8 (data router, one splat route; the real routes are the `<Routes>` in `apps/web/src/App.tsx`) + TanStack Query. Styling is **one plain CSS file**, `src/styles/app.css` (about 8,000 lines, BEM-ish class names), plus `src/styles/tokens.css` (132 lines of CSS custom properties). No CSS framework, no CSS-in-JS. Fonts are `@fontsource-variable/bricolage-grotesque` (display) and `figtree` (body), imported in `main.tsx`.

**Theme.** `tokens.css` defines a light palette ("cool paper + cobalt") in `:root`, a dark palette under `prefers-color-scheme: dark` and under `[data-theme='dark']`. `theme.ts` (`useTheme`) stores system / light / dark in localStorage; an inline script in `index.html` applies it before first paint. Token names: `--bg --surface --surface-2 --ink --ink-muted --line --line-strong --accent --accent-ink --accent-soft --danger --focus --status-bad|mid|good` (the last three are _score_ colours for the gauge, not game status). Game status colours live as `.badge--playing|paused|finished|abandoned` rules (`app.css` ~1449-1502); there is no single status-to-colour helper.

**Shell.** `components/Shell.tsx` (432 lines) renders, for signed-in users only: a skip link; a `.mobile-bar` (hamburger + logo + `DevBadge`) under 900 px; the `<aside class="sidebar">` (logo, "Search games" link to `/search`, nav groups, collapse toggle, `UserMenu`); a `.tabbar` bottom bar (Playing, Queue, Collection, Search, You); and `.content` with `<main>` (inside an `ErrorBoundary`) followed by `<Footer sitemap />`. Under 900 px the sidebar is a full-screen circular-reveal drawer. Collapse-to-icons already exists (localStorage `gq.sidebar.collapsed`, with `Tooltip`s). `/` already focuses search by navigating to `/search`. Current nav: Play (Now playing, Queue, Pick, Ask AI) / Library (Collection, Backlog, Lists, Wishlist, Discover) / Insights (Stats, Save File in recap season). The footer repeats the nav as a site map, adds the copyright, the "Preview: ... data could be lost" line and the IGDB attribution + Credits link. `PreviewNotice.tsx` already has a `DismissiblePreviewNotice` (localStorage), but it only shows on Home.

**Public profile.** `/u/:username` and sub-pages are sibling routes _outside_ `Shell` (they work logged out), using `PublicHeader` + `Footer`.

**Collection** (`routes/CollectionPage.tsx`, `view` = `all` | `backlog`; `/backlog` is a second route to the same component). Filters live in the URL (`status platform genre series tag favorite q sort`). A title search box and sort select sit above a two-column `.browse` layout: card grid (or list) on the left, `FacetSidebar` on the right (checkbox groups with counts from `GET /entries/facets`). Paging is "load more" (`usePagedEntries`, 48 per page, `LoadMore`), no virtualization. `GameCard` shows the cover with title/meta/chips only on hover (`.card__info`), so **status is not visible at rest**. Layout (grid/list) is `useLayout`, stored in localStorage under `gq_collection_layout`. `AddGameDialog` is the add flow; `/search` (`SearchPage`) is a separate IGDB search page.

**Game detail.** Two routes: `EntryPage` (`/games/:id`, owned) and `GameDetailPage` (`/games/igdb/:igdbId`, not owned). `EntryPage` is a two-column `.entry__layout`: left = cover plus a stack of screenshots (`Screenshots`), right = a long `.stack` of panels: title/genres/series/favorite/`ScoreGauge`, summary (not clamped), Ask-AI link, `StatusPanel` (actions as buttons), `JournalPanel`, `HistoryPanel`, `TimeToBeat`, `SimilarGames`, `ListsPanel`, `PlatformsEditor`, "My take" (`StarRating`), `NotesPanel`, `TagsEditor`, remove button. `EntryActionBar` is a sticky bottom bar on phones. The right column runs much longer than the left (see `game-owned-1280`).

**Now playing** (`routes/Home.tsx`). Greeting hero with logo tile, then "Playing" (`PlayingCard` list: cover, title, since-date, Pause / **Finished (primary)** / Abandon), "Paused" (compact cards), `UpNext` (first 4 queue games as `GameCard`s with position badges, no reorder here), `ReleasingSoon`. Reorder lives only on the full `/queue` page (`ListPage`, dnd-kit). A brand-new account sees `Welcome` instead.

**Search.** `/search` hits `GET /igdb/search` (`useGameSearch`); results carry `entryId` and `wishlisted` but not the entry's status. The library is searched through `GET /entries?q=`.

## 3. Files each phase will touch

Paths are under `apps/web/src/` unless noted. Tests: Vitest for pure helpers; I'll add the status colour helper and any pure logic with tests, and re-run `npm run typecheck`, `npm test`, `npm run format:check` per phase. `ARCHITECTURE.md` / `OVERVIEW.md` are updated in the same PR when pages or nav change (project rule).

### Phase 1: Foundation and shell (branch `redesign/phase-1-shell`)

- `styles/tokens.css`: brief tokens (dark = brief, light derived), aliases for old names, radii, shadows, `--font-display/--font-body`.
- `main.tsx`, `index.html`, `apps/web/package.json`: swap fonts; update inline splash colours/theme-color in `theme.ts` (`THEME_COLORS`).
- New `statusColor.ts` (+ `statusColor.test.ts`): the single state-to-token map (`playing|paused|finished|abandoned|unplayed|wishlist`), plus the chip component `StatusChip.tsx` (dot + colour + label). Existing `.badge--*` rules re-point to it.
- `components/Shell.tsx`, `styles/app.css` (sidebar, mobile bar, tabbar, content, footer sections): new nav groups (Play: Now playing, Queue / Library: Collection, Lists / Explore: Pick for me, Discover, Ask AI / Insights: Stats), "Search or jump to..." button (visual; opens existing `/search` until Phase 2), icon-rail collapse kept, hamburger kept on phones for now.
- `components/UserMenu.tsx`, `components/DevBadge.tsx`: DEV badge moves into the user block; Data, Account, theme, IGDB credits live in the menu.
- `components/Footer.tsx`: shell footer removed (kept for public pages, minus the site map); `components/PreviewNotice.tsx`: one dismissible banner mounted by the shell; `routes/Home.tsx`: drop the page-level notice.
- `App.tsx`: profile routes under a shell-or-public layout. The `/backlog` and `/wishlist` redirects wait for Phase 3, so those pages stay reachable in Phase 1 (see open question 2).
- `components/Logo.tsx`, `routes/ProfilePage.tsx`, `components/PublicHeader.tsx`: use the shell when signed in.
- Docs: `ARCHITECTURE.md` (web shell/nav), `OVERVIEW.md` if the shell diagram changes.

### Phase 2: Global search and mobile search (`redesign/phase-2-search`)

- New `components/CommandPalette.tsx`, `api/search.ts` (merges `GET /entries?q=` and `GET /igdb/search` into one result model, cached by query), `components/QuickAddSheet.tsx`, shared recent-searches hook; `Shell.tsx` (⌘K and `/`, sidebar button), `App.tsx`, `routes/SearchPage.tsx` rebuilt as the phone landing/results, bottom tab bar (Play, Library, Search, Stats, More) and More sheet, `routes/CollectionPage.tsx` (remove search box), `Footer` link removed, `AddGameDialog.tsx` reuses the sheet's add logic. Server: none (existing endpoints; uses `entryId`/`wishlisted`).

### Phase 3: Collection (`redesign/phase-3-collection`)

- `routes/CollectionPage.tsx` (tabs, top filter bar, density switch, wishlist tab), `components/FacetSidebar.tsx` (becomes the filter popovers; sidebar deleted), `components/GameCard.tsx` and `GameRow.tsx` (chips, progress), new `components/WallTile.tsx`, `components/LayoutToggle.tsx` (Wall/Grid/List, per-user), `components/GridSkeletons.tsx` (skeletons per layout, required by project rules), `routes/WishlistPage.tsx` (content reused in the tab), `App.tsx` redirects, `styles/app.css` (.grid/.card/.browse/.filters).
- Server and shared: `packages/shared/src/collection.ts` (`ENTRY_SORTS` + `igdb`), `apps/server/src/services/entries.ts` (igdb sort; stop genre/theme tag pre-fill; lowercase new tags), tests in `apps/server/test/collection.test.ts` and `favorites/notes` as needed; `ARCHITECTURE.md`.

### Phase 4: Game detail (`redesign/phase-4-game-detail`)

- `routes/EntryPage.tsx`, `routes/GameDetailPage.tsx`, `components/Screenshots.tsx` (+ `ImageLightbox`), `components/PlaythroughPanels.tsx` (`StatusPanel` becomes primary button + segmented control; history collapsed), `components/EntryActionBar.tsx`, `components/StarRating.tsx`, `components/NotesPanel.tsx`, `components/ScoreGauge.tsx` + `gauge.ts` (keeps tier rules; green token), `components/PageSkeletons.tsx`, `styles/app.css` (.entry*).
